1. What this Project does

Camicia is a volunteer distributed-computing project, built on BOINC, that exhaustively searches
permutations of a 52-card deck to find games of Beggar-My-Neighbour (known in Italy as "Camicia," the
game this Project is named after) that loop forever, or that run unusually long before eventually
ending. When you attach a computer to this Project, it will download work units, run computations
using your computer's processor and memory, and return the results.
