# Wiki skeleton

Bare structure only -- pages below have headers and a short note on what
each is for, no real content yet. Kept here in-repo (rather than directly
in GitHub's separate wiki repo) so the skeleton itself goes through the
same review/diff process as everything else; the actual content, when
written, can either stay here or be copied into the GitHub Wiki proper --
not decided yet.

Distinct from `RUNBOOK.md`: the runbook is "what to do when something's on
fire," reactive and incident-shaped. This is meant to be the discursive,
architectural, background reading -- how the pieces fit together and why,
for someone who has time to actually read before they need it.
